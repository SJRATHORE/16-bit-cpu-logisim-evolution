# Contributions and project provenance

This repository is an archive of a course CPU project, including historical iterations and supporting subcircuits. If you spot an error in the documentation, open a GitHub issue or submit a pull request describing the correction. Please do not silently replace the original `src/16_Bit.circ` file or alter historical memory-image tests. Changes to the hardware should be accompanied by a description and, when possible, a reproducible test.

Third-party textbooks and course PDFs are cited but not included in this public archive.
